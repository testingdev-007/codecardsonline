📖 Quick Start Rules: Coding vs. Bugs

A fast, tactical, educational card duel where you assemble software while defending against and deploying glitches!

1. Memory Architecture: Hand vs. Stack

• Your Hand (5 Cards): Private RAM held in secret. Unplayed cards left in hand at endgame score 0 points.
• Your Stack: The public tabletop column in front of you. Only cards in your Stack determine your score!

2. Turn Loop

1. DRAW 1 card from the central deck into your hand.
2. PLAY 1 card (onto your Stack, opponent's Stack, or Discard).

3. Play on Any Stack (Baiting & Sabotage)

Both Code (+) and Glitches (-) can target either player's stack. Boost yourself, hinder the AI, or plant a +5 Code card onto the AI as bait to steal back with Copy & Paste!

4. Instant Reactions (Undo!)

An Undo! (Ctrl + Z) in your hand can instantly react out-of-turn to cancel hostile Glitches or Commands!

🎓 The 31 CS Concepts Compendium

Every card translates fundamental computing into beginner-accessible logic:

🟢 Code Cards (+1 to +5 Points)

Variables (+1): Storage boxes for numbers, words ("Hello"), flags (True/False), and contact list dictionaries.
Loops (+2): Automatic repeaters (For, While, Do-While, Auto-Retry) so you never write repetitive code twice.
Decisions (+3): Smart cause-and-effect rules (If-Then, If-Else, Switch/Case) guiding software logic.
Modular Architecture (+4): Reusable Functions, App Templates, and Data Cloud Links.
Optimized Algorithms (+5): Fast Search (High-Low halving) and Sorting Algorithms.

🔴 Glitches (-1 to -4 Penalty Points)

Typo! (-1): Spelling slips or missing semicolons.
Infinite Loop (-2): A broken loop that spins endlessly with no stop condition.
Frozen Screen (-3): App overwhelmed by tasks and locked up.
Total Crash (-4): Fatal unrecoverable runtime crash.

⚡ Commands & ★ Game-Changers

Undo! (Ctrl+Z): Popping the last hostile action off the execution stack.
Copy & Paste: Duplicating valuable code from rival stack into yours.
It's a Feature, Not a Bug!: Inverts ALL negative Glitches in your stack to positive points!
Overclock!: Doubles your Code points (4x if stacked twice!).
